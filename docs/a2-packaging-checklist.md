## Recreate the Zip Files

Run from PowerShell after saving all intended changes and committing the delivery version:

```powershell
Set-Location 'E:\workplace\user2'
.\scripts\package-a2.ps1
```

The script uses explicit file lists, excludes private settings and dependencies, and also copies `charityevents_db.sql` to `submission/`. A local `SHA256SUMS.txt` and `build-manifest.json` identify the source commit and file contents. The manifest warns if the working tree was not clean. Re-running intentionally replaces the generated artifacts under `submission/`.

The SQL file is unchanged from `database/charityevents_db.sql`. It drops the named database, so use the setup guide's restore precautions.
